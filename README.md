# MITRC LibSphere – Library Management System

## 📚 About the Project

MITRC LibSphere is a web-based Library Management System designed to make library operations easier for students and library administrators.

The project provides a user interface for accessing library services and managing books.

## 🎯 Objectives

- Create a simple and user-friendly library interface.
- Provide a login page for library users.
- Design dashboards for students and librarians.
- Make library operations easier to navigate.

## ✨ Features

- Login interface
- Student dashboard
- Librarian dashboard
- Manage books
- Issue and return books
- Manage users
- Suggestions and voting
- Library navigation interface

## 🛠️ Technologies Used

- **HTML5** – Structure of web pages
- **CSS3** – Styling, layouts, colors, and responsiveness
- **JavaScript** – Interactive page elements and navigation
- **Font Awesome** – Icons
- **Google Fonts** – Typography

## 🚀 How to Run the Project

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `student/login.html` to view the login page.
4. Use the Live Server extension to launch the page in your browser.
5. Open the other HTML pages to explore the interfaces.
